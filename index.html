Standards we design to

Built for the rules your auditors check

We map every design to the Saudi frameworks that apply to you and check AWS designs against the Well-Architected Framework, so the evidence exists before anyone asks for it.

  • NCA ECC-2:2024The National Cybersecurity Authority’s Essential Cybersecurity Controls — the baseline for organizations in the Kingdom.
  • NCA CCC-2:2024Cloud Cybersecurity Controls — the extra requirements when your systems or data run in the cloud.
  • SAMA CSFThe Saudi Central Bank’s Cyber Security Framework, for banks, insurers, finance and payment companies.
  • PDPLThe Personal Data Protection Law, which governs how personal data is collected, stored and transferred.
  • ISO 27001The international standard for information security management.
  • AWS Well-ArchitectedAWS’s review of security, reliability, performance and cost — applied to every AWS design.

Need data to stay in the Kingdom? We design for it: on-premises, in Saudi data centers, or in the AWS Region in Saudi Arabia, which AWS has announced for launch by December 2026.
